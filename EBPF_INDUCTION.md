# eBPF Introduction

## Overview of the eBPF

Explores the core concept of Extended Berkeley Packet Filter (eBPF) as an evolution within the Linux Kernel.

## What is eBPF?

Focuses on how eBPF runs safely sandboxed bytecode directly inside the kernel to extend system capabilities dynamically.

## The Execution Model

Breaks down the full lifecycle pipeline from writing high-level code, compilation via LLVM/Clang, verification by the kernel verifier, to final Just-In-Time (JIT) execution.

## Primary Use Cases

Highlights practical system implementations including IP network, high-speed packet processing via XDP, runtime auditing, and deep system observability using tracepoint syscalls, kprobe, etc.
